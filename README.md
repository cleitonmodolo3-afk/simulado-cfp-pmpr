# Simulado CFP PMPR — GitHub Pages

## Como publicar
1. Crie um repositório no GitHub.
2. Envie `index.html`, `style.css`, `script.js` e `questoes.js`.
3. Vá em **Settings → Pages**.
4. Em Source, selecione **Deploy from a branch**.
5. Selecione a branch `main` e a pasta `/ (root)`.
6. Salve e aguarde a publicação.

## Observação sobre o gabarito
O PDF materializado nesta conversa não preservou marcações de cor verde/vermelha como dados de texto/annotações no arquivo disponível ao processamento. Por isso, o banco deste pacote usa gabarito V/F inferido pela correção factual das afirmações.
